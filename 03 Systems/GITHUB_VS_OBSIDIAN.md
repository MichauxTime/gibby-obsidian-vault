# GitHub vs Obsidian

## Obsidian is for
- decisions
- architecture notes
- project memory
- meeting notes
- research
- changelog summaries
- operating rules
- reusable snippets with explanation

## GitHub is for
- source code
- line-by-line diffs
- branches
- PR review
- rollback
- release history
- collaboration on implementation

## Rule of thumb
- If the thing must run, GitHub matters.
- If the thing must be remembered, Obsidian matters.
- If both are true, update both.
