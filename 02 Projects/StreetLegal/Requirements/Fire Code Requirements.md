# Fire Code Requirements

Cross-jurisdiction hub for fire-code / fire-marshal requirements on mobile food units.

## Universal layer (true almost everywhere)
- Trucks that **cook with open flame, propane, or generate grease-laden vapors** generally require a **fire marshal inspection** and/or a fire operational permit before health/vending permits are issued.
- Common universal items: **Class K fire extinguisher**, automatic **fire-suppression system** over cooking equipment (esp. with fryers/grills), **propane/LP-gas** tank securing + leak/pressure standards, clearances, and posted inspection tags.
- Fire inspection is frequently a **prerequisite step** in the permit sequence (often before the health permit).

## Variation layer (what differs by jurisdiction)
- Whether fire inspection is a standalone permit vs. folded into the health/vending process.
- Suppression-system thresholds (some require it for any cooking; some only above a heat/appliance threshold).
- Propane tank size limits, number of tanks, and placement rules.
- Annual re-inspection cadence and fees.
- Some cities publish a fire form/portal; others are contact-only (e.g. call the fire prevention office).
