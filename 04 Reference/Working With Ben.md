# Working With Ben

Durable profile of how to work with Ben effectively. Work-relevant only — **no personal/family info** (his explicit boundary).

## Communication (most important)
- **Has ADHD.** Keep replies SHORT and answer-first. Lead with the verdict, then a few scannable bullets max. He stops reading walls of text.
- **Click-in model:** give the point, let him ask for more / drill in. Don't front-load everything.
- Do the deep work in tools/docs/Obsidian; keep the visible chat tight.
- Discord is his primary interface. Prefers clickable buttons/components when choosing between options.
- He uses voice input — watch for misrecognitions (e.g. "crayons" = "crons").

## What he values
- **Real execution + proof.** Screenshots, before/after, live verification. "Page loads" is not proof.
- Hates fake completion, weak verification, noisy status dumps, and repeating himself after a correction.
- **Autonomy:** ship proactively, default to action. Only stop to ask on irreversible/external actions.
- Commit + push every meaningful change. Verify immediately after a fix.

## How he operates
- **Frontier-orchestrator:** he's the owner/decider, not the lone executor. Delegate to subagents/specialists; he decides and ships.
- Fine running **many cron jobs** as long as they're **spaced across the day** (no same-minute collisions). Don't over-warn about adding crons — declustering is the fix, and there are plenty of hours.
- Demo-first handoffs before he sells/ships something: walkthrough, screenshots, known issues, a way to test it himself.

## Hard rules he's set (see also auto-memory)
- No direct Anthropic/OpenAI API keys — use subscription-routed/local paths.
- Defensible data only: rankings/claims must be backed by real, linkable sources — never assumptions.
- Match StreetLegal's existing light design system; never invent dark schemes.

## Businesses he runs
- **StreetLegal** — food-truck permit/compliance platform (primary focus)
- **Stylograph** — AI handwriting platform (B2B, college athletics/donor comms)
- 3D print files (Gumroad/Etsy)
- Gibby system — me, his autonomous operator
